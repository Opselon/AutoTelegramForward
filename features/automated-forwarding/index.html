    Automated Forwarding

    Forwarding Modes: Direct vs Clean Copy

    The operational forwarding modes: Direct native MTProto forward, Clean Copy that strips author attribution, and per-target forum topic routing.

    Overview

    AutoTelegramForward supports real-time, event-driven message dispatch between any Telegram entities: public channels, private channels, supergroups, forum topics, and direct chats.

    Forwarding Modes: Direct vs Clean Copy

    Mode: DIRECT

    Native MTProto Forward

    Uses Telegram's native forward_messages() call. The delivered post retains the original author banner ("Forwarded from Channel X").

    • Fastest delivery (sub-100ms)
    • Does not allow modifying text or stripping links
    • Fails if source channel has restricted forwarding
    Mode: COPY (Recommended)

    Clean Copy Mode

    Extracts raw media and text, passes it through the Cleaners and Shortcodes engine, and posts it as an authentic new publication.

    • No "Forwarded from" watermark
    • Full support for custom headers & footers
    • Strips unwanted ads, URLs & mentions

    Telegram Forum Topics Support

    AutoTelegramForward fully supports modern Telegram Supergroups with Forum Topics enabled. By supplying the topic ID (e.g. message_thread_id), messages can be routed precisely into specific topics rather than cluttering the General feed.

    Execution Priority & Ordering

    In high-traffic news channels, maintaining chronological order is critical. ATF's durable queue uses per-chat serial leases to guarantee that consecutive messages from a single source are processed strictly in sequence without out-of-order race conditions.

    NextDestination Management
    AutoTelegramForwardATF

    Self-hosted Telegram routing: many sources to many targets, per-task content rules, optional AI rewriting, durable ordered delivery and a fail-closed multi-tenant control plane.
