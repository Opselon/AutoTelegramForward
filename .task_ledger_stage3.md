## Schema facts (must be preserved)

- `delivery_jobs.intermediate_chat_id/intermediate_message_id/delivery_stage` exist on both backends and are currently **unused by Go** — the natural stage-1 checkpoint.
- SQLite migrations are keyed `MIGRATIONS[n]` in `core/infrastructure/persistence/database.py`, currently max **32** → new table = migration **33**.
- PostgreSQL init is `initialize_postgres_schema()` in `postgres_repositories.py`; `scripts/postgres/schema.sql` must stay byte-compatible with it (Stage 2 fix `f0659f4`).
- `bot_tokens` is **SQLite-only** (PG schema has no such table) → token resolution must live in the Python Runtime, which already owns the Core's repos.
- `forward_rules` metadata JSON carries `auto_pause` and `branding_hop` (§`branding.BRANDING_META_KEY`); the worker's rule projection reads `metadata` already.
