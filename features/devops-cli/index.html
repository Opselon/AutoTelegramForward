    DevOps CLI & upgrades

    DevOps CLI, Validate & Self-Upgrade

    24 command groups cover setup, tasks, logs, backups, docker, k8s and TLS, with a read-only validator for CI and an upgrade engine behind a health gate.

    OperationsNew in v2.0

    atf validate is read-only and exits non-zero on failure, so it works as a pre-deploy gate in any pipeline.

    Lifecycle in one place

    The validator

    atf validate runs read-only checks and exits 0 only when every one passes. --strict promotes warnings to failures, --runtime adds live checks against the running stack, and --deep runs the repository audits. --json prints exactly one JSON object, so a pipeline can consume it.

    Upgrades with a health gate

    atf system upgrade pulls, rebuilds, recreates the containers, repairs the compose network aliases and then requires the health check to pass. If the stack does not come back healthy, the failure is loud rather than a half-migrated install.

    Container recreation is the step that most often breaks networking: a manually recreated container loses its compose alias. The upgrade path reconnects the aliases, so the core, api and web names stay resolvable to each other and to the external AI bridge.

    Scriptable output

    Note

    Every line the CLI writes passes a single redaction filter, so a bot token or API key cannot leak into a transcript or a CI log.

    Frequently asked

    Can I use the validator in CI without touching a running stack?

    Yes. atf validate is read-only by default; --runtime only adds checks, and nothing it runs mutates the deployment.

    How do I know an upgrade worked?

    atf system upgrade ends in a health gate over all four services. atf system services reports state, health, endpoint and version per service, and exits non-zero if anything is down.

    Do I need docker to use the CLI?

    No. There are docker, source and portable modes; atf platform prints the exact install commands for the host you are on, and the portable build is a single standard-library file.
